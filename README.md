this webpage is a "personal site" that will tell you some cool things about me! it was created as a small project for a summer club I'm participating in.  

## features
* cool starry header that links back to my main website
* two paragraphs about me and my <i>not-suspicious</i> hobbies
* two paragraphs about things <i>you</i> can explore on the webpage
* fun bonuses for my hobbies, where you can find hidden links and explore those hobbies
* previews for three of my games, with a variety of game types: a tycoon game, a silly pie game, and a logic game
* fun CSS animations throughout the page!
